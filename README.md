# HR APPLICATION SYSTEM FINAL PROJECT

### AI Usage Explanation

In the development of this Human Resource Application Management System, AI tools were utilized as a learning and productivity aid throughout the implementation phase. Specifically, AI assistance was used in the **following areas:**

### Code Debugging and Error Resolution

AI was consulted to help diagnose and resolve technical errors encountered during development, such as database column mismatches, designer compatibility issues with Windows Forms, and selection event handling bugs. This allowed for faster troubleshooting while still requiring us to understand and apply each fix.

### Form Implementation Guidance

AI provided structural guidance in connecting pre-designed Windows Forms to the backend database (MySQL), including writing SQL queries, wiring up event handlers, and ensuring data flows correctly between the UI and the database layer.

### Feature Development

AI assisted in implementing specific system features such as the dashboard statistics, CSV export and print functionality in the Reports module, the Maintenance module for managing lookup tables, and the Change Password feature for applicant accounts.

### Code Consistency

AI helped maintain consistent coding patterns across all forms such as using transactions for multi-step database operations, session management, and status history logging, ensuring the codebase remained clean and uniform throughout the project.
Throughout the process, all AI-generated code was reviewed, tested, and integrated by us. AI served as a technical reference and assistant, not a replacement for understanding. Final decisions on system design, logic flow, and implementation were made by the group.
